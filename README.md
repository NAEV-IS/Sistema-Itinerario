# B2B Travel Itinerary and Operations Platform

Este repositorio contiene la documentacion tecnica, seleccion de stack tecnologico y el diseno de interfaz de la solucion B2B desarrollada para la optimizacion operativa y la gestion de itinerarios turisticos en Petru DMC.

> Nota de Confidencialidad: El codigo fuente de este proyecto es propiedad privada de Petru DMC y no se encuentra disponible de forma publica. Este espacio esta destinado a exhibir el proceso de relevamiento, arquitectura, diseno UX/UI y gestion del proyecto.

## Descripcion del Proyecto
El sistema es una solucion web integral disenada para transformar procesos manuales complejos de armado de itinerarios en flujos digitales eficientes. Permite al equipo comercial estructurar rutas, gestionar bases de datos de excursiones y generar propuestas personalizadas para clientes corporativos.

## Mi Rol y Responsabilidades
Como Software Developer Intern, lidere las etapas iniciales del ciclo de vida del producto y colabore en la definicion del desarrollo full-stack:

1. Relevamiento y Documentacion: Conduccion de analisis de requerimientos con stakeholders no tecnicos y elaboracion de la documentacion funcional y tecnica del sistema.
2. Diseno UX/UI: Creacion desde cero de los flujos de trabajo, wireframes y prototipos interactivos de alta fidelidad orientados a la eficiencia del usuario.
3. Arquitectura y Modelado: Diseno del modelo de datos relacional y colaboracion en la definicion de la estructura modular del proyecto.

## Stack Tecnologico Definido
La solucion se estructuro utilizando un enfoque de Monorepo basado en las siguientes tecnologias:
* Diseno y Prototipado: Figma
* Desarrollo Frontend: React, TypeScript
* Desarrollo Backend y ORM: Node.js, Prisma ORM
* Base de Datos: PostgreSQL
* Gestion y Agilidad: Metodologias Agiles (Scrum/Sprints), Trello, Slack, Git

## Interfaz de Usuario y Prototipado (Figma)
El diseno visual se enfoco en la usabilidad y la reduccion de la carga cognitiva del equipo comercial, asegurando interfaces limpias, componentes reutilizables y un flujo de navegacion fluido.
