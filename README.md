# B2B Travel Itinerary and Operations Platform
Este repositorio contiene la documentación técnica, selección de stack tecnológico y el diseño de interfaz de la solución B2B desarrollada para la optimización operativa y la gestión de itinerarios turísticos en Petru DMC.
> 🔒 **Nota de Confidencialidad:** El código fuente de este proyecto es propiedad privada de Petru DMC y no se encuentra disponible de forma pública. Este espacio está destinado a exhibir el proceso de relevamiento, arquitectura, diseño UX/UI y gestión del proyecto.
## 📋 Descripción del Proyecto
El sistema es una solución web integral diseñada para transformar procesos manuales complejos de armado de itinerarios en flujos digitales eficientes. Permite al equipo comercial estructurar rutas, gestionar bases de datos de excursiones y generar propuestas personalizadas para clientes corporativos.
## 🧑‍💻 Mi Rol y Responsabilidades
Como Software Developer Intern, lideré las etapas iniciales del ciclo de vida del producto y colaboré en la definición del desarrollo full-stack:
1. **Relevamiento y Documentación:** Conducción de análisis de requerimientos con stakeholders no técnicos y elaboración de la documentación funcional y técnica del sistema.
2. **Diseño UX/UI:** Creación desde cero de los flujos de trabajo, wireframes y prototipos interactivos de alta fidelidad orientados a la eficiencia del usuario.
3. **Arquitectura y Modelado:** Diseño del modelo de datos relacional y colaboración en la definición de la estructura modular del proyecto.
## 🔄 Análisis de Procesos (AS-IS vs. TO-BE)
Para fundamentar el desarrollo, se realizó un análisis de los procesos para justificar la necesidad del software:
**Escenario Anterior (AS-IS)**
* Construcción manual de itinerarios utilizando hojas de cálculo sin estructura de datos unificada.
* Redacción libre para la descripción de los días de viaje, propensa a inconsistencias.
* Selección de proveedores desde catálogos descentralizados.
**Solución Implementada (TO-BE)**
* Formularios controlados para la construcción de itinerarios día por día con datos estructurados.
* Catálogo centralizado en una base de datos interconectada de proveedores (hotelería, traslados, excursiones).
* Generación automatizada de documentos y propuestas con formato estándar y profesional.
## 🏗️ Stack Tecnológico Definido
La solución se estructuró utilizando un enfoque de Monorepo basado en las siguientes tecnologías:
* **Diseño y Prototipado:** Figma
* **Desarrollo Frontend:** React, TypeScript
* **Desarrollo Backend y ORM:** Node.js, Prisma ORM
* **Base de Datos:** PostgreSQL
* **Gestión y Agilidad:** Metodologías Ágiles (Scrum/Sprints), Trello, Slack, Git
## 🎨 Interfaz de Usuario y Prototipado (Figma)
El diseño visual se enfocó en la usabilidad y la reducción de la carga cognitiva del equipo comercial, asegurando interfaces limpias, componentes reutilizables y un flujo de navegación fluido.
